## วันนี้ (ก่อนวัน demo)

1. **Login แล้วเลือกบัญชีที่จะใช้ demo** — ดูว่ามีข้อมูลพอเล่าเรื่อง:
   - เมนู **บริษัท** มีหลายสิบบริษัท · บางบริษัทมีคน 3–10 คน
   - เมนู **ดีล** มีดีลกระจายหลายขั้น · **แคมเปญ** มีอย่างน้อย 1 แคมเปญ
   - ถ้าบัญชีว่าง: บัญชีที่สมัครเองโหลดข้อมูลสมมุติได้ในขั้นตั้งค่าบัญชี · ถ้าไม่ได้ บอกผม — มีแผนสำรองด้านล่าง
2. **ตั้งค่า › ลูกค้าของบัญชีนี้ = "ขายให้บริษัท"** (เมนูจะมี บริษัท · ผู้ติดต่อ · ดีล · งาน · แคมเปญ · รายงาน · บนมือถือเมนูอยู่แถบล่าง: หน้าแรก · บริษัท · ผู้ติดต่อ · ดีล · เพิ่มเติม)
3. **ซ้อมเดินตามสคริปต์หนึ่งรอบ** แล้วจดชื่อบริษัท/ดีล/คนที่จะเปิดจริง (ใส่ในช่อง ____ ด้านล่าง) — อย่าเลือกสด
4. ปุ่ม **"สร้างสรุปด้วย AI"** (หน้าบริษัท): กดดูก่อน 1 ครั้ง — ถ้าบัญชีอยู่ในช่วงทดลอง AI จะปิด ให้ใช้ "สรุปอัตโนมัติ" ที่อยู่ในหน้าเดียวกันแทน
5. เตรียมเครื่อง: เบราว์เซอร์แยกโปรไฟล์ · ปิดแท็บอื่น · ซูม 110–125% ถ้าฉายจอ · ปิดการแจ้งเตือน

**แผนสำรอง (เน็ตล่ม/ข้อมูลไม่พอ):** เดโมในเครื่อง — ซ้อมครบทุกฉากแล้ว 22 ต.ค. 2569 ผ่านทั้งหมด
- เตรียม: `npm run demo:seta` (ล้างแล้วสร้างฉากใหม่ทุกครั้ง) แล้วเปิด dev server · บัญชี › สลับ › "Sunline Expo (สมมุติ)"
- ชื่อที่ใช้ในแต่ละฉาก (ข้อมูลสมมุติ ชื่อเหมือนเดิมทุกครั้งที่สร้างใหม่):

## เส้นเรื่อง (20 นาที)

> แกนของเรื่อง: **"ข้อมูลลูกค้าเดิมที่กระจัดกระจาย → รู้ว่าวันนี้ต้องคุยกับใคร เรื่องอะไร และคุยได้ตามกฎหมาย"**

### 1 · หน้าแรก — "เปิดมารู้เลยว่าวันนี้ทำอะไร" (2 นาที)
- **หน้าแรก**: เรียงตามหมวดตายตัว — **หยุดติดต่อ** → งานครบกำหนด → เลยกำหนด → **ลูกค้าที่ไม่ได้คุยนาน**
- งานแคมเปญมีปุ่ม **"บันทึกผล"** ทำจากหน้านี้ได้เลย · งานทั่วไปมีปุ่ม **"เสร็จแล้ว"**
- ชี้ **"คนที่รู้จักย้ายบริษัท"**: *"คนที่ทีมรู้จักย้ายไปบริษัทใหม่ — ระบบบอกเองจากไฟล์ที่นำเข้า"* (จุดที่ลูกค้ามักว้าว)
- พูด: *"ไม่มีคะแนนลึกลับ — ทุกบรรทัดบอกเหตุผล"*

### 2 · แฟ้มบริษัท — "ภาพเดียวครบ" (5 นาที) · บริษัท: ____
- **บริษัท** → เปิดบริษัทที่เตรียมไว้
- แท็บ **ภาพรวม**: สรุปก่อนพบลูกค้า · คนสำคัญ · **ใครในทีมรู้จัก** (ใครในทีมรู้จักใครในบริษัทนี้)
- แท็บ **คน**: สังกัดตามเวลา — ใครยังอยู่ ใครย้ายไปแล้ว (*"ข้อมูลเก่าไม่หลอกเรา"*)
- **บันทึกกิจกรรม** สั้น ๆ + ใส่ **งานถัดไป** → ขึ้นทั้งหน้าบริษัท หน้าคน และงาน
- (ถ้ามี) แท็บ **บริษัทในเครือ**: ยอดรวมทั้งกลุ่ม

### 3 · ข้อมูลซ้ำ — "ไม่เกิดบริษัทซ้ำ" (2 นาที)
- **+ ใหม่ › บริษัท** → พิมพ์ชื่อบริษัทที่มีอยู่แล้วแบบไม่มี "บริษัท/จำกัด" → ระบบเปิดแฟ้มเดิมให้
- พิมพ์ชื่อคล้าย ๆ → ระบบเตือนก่อนสร้าง พร้อมเหตุผล

### 4 · ดีล — "ไปป์ไลน์ที่ไม่โกหก" (4 นาที) · ดีล: ____
- **ดีล** → มุมมอง **ไปป์ไลน์** · เปลี่ยนขั้นจากช่องเลือกบนการ์ด (หรือลาก)
- (ต้องตั้งกฎขั้นไว้ก่อน: ตั้งค่า › กฎขั้นของดีล › "เสนอราคา" ต้องมีมูลค่า) เลื่อนดีลที่ไม่มีมูลค่าไป "เสนอราคา" → **ถูกปฏิเสธพร้อมบอกว่าขาดอะไร**
- เปิดดีล: Path ขั้น · อยู่ขั้นนี้กี่วัน · แพ็กเกจ · คนในดีลพร้อมบทบาท (ผู้ตัดสินใจ/ผู้อนุมัติงบ)
- **ปิดได้พร้อมเหตุผล** → ระบบสร้าง **ดีลต่อสัญญาปีหน้า** ให้ (แพ็กเกจเดิม)

### 5 · แคมเปญ + PDPA — "จุดขายที่คู่แข่งไม่มี" (4 นาที) · แคมเปญ: ____
- (ถ้าถูกถามว่าสร้างยังไง: **แคมเปญ › + แคมเปญ** เปิดหน้าสร้างแยก)
- เปิดแคมเปญที่มีรายชื่อแล้ว → แต่ละคนมีป้าย **ใช้ได้ / ต้องตรวจก่อน / ห้ามติดต่อ** พร้อมเหตุผล
- พูด: *"ระบบตัดสินตามวัตถุประสงค์และฐานกฎหมายทุกครั้ง — ไม่ใช่ติ๊กยินยอมช่องเดียว"*
- เปิดหน้าคนที่ป้าย "ใช้ได้" › แท็บ **ความยินยอม** → ชนิด **คัดค้าน** (ค่าตั้งต้น) · หลักฐาน "โทรแจ้งไม่ต้องการรับข้อเสนอ" → บันทึก
  → ระบบตอบ *"ยกเลิกเป้าหมายแคมเปญและงานที่ค้าง 1 รายการตามนโยบาย"* · กลับไปแคมเปญ: คนนั้นเป็น **ห้ามติดต่อ** พร้อมเหตุผล
- (เสริม) **ตั้งค่า › คำขอสิทธิ**: รับคำขอลบ/ขอดูข้อมูลตาม PDPA มีกำหนดเวลา

### 6 · รายงาน — "ผู้บริหารเห็นอะไร" (2 นาที)
- **รายงาน**: ไปป์ไลน์ตามขั้น · ความเร็วไปป์ไลน์ · **ทำไมได้/ทำไมไม่ได้**
- **รายงานเลือกมิติเอง**: เช่น มูลค่าดีล × อุตสาหกรรม
- **พยากรณ์และเป้า**

### 7 · ปิด (1 นาที)
- นำเข้าไฟล์ Excel เดิมได้ (ตรวจคนซ้ำให้ก่อนรวม · ย้อนได้ทั้งชุด) · ถังขยะ 30 วัน · สุขภาพข้อมูล
- **+ › นามบัตร (ถ่ายรูป)**: ถ่าย/อัปโหลดหลายใบ → ระบบอ่านในเครื่อง (รูปไม่ออกจากเครื่อง) → ช่องที่ไม่แน่ใจขึ้นกรอบสีเหลือง → บันทึกทีเดียว · ซ้อมด้วยนามบัตรจริงของตัวเองก่อน
- ถาม: *"ตอนนี้ข้อมูลลูกค้าของคุณอยู่ที่ไหนบ้าง?"* → ชวนทดลองกับไฟล์จริง (หลังเซ็นข้อตกลงข้อมูล)
