## 2 · ถอดภาพอ้างอิง — อะไรทำให้มันดูดี

1. **UI ไม่มีสี สีอยู่ในภาพเท่านั้น** — ตัวหนังสือดำ/เทา เส้นบาง ปุ่มกรอบเทา · ภาพไล่สีด้านล่างทำหน้าที่ "แบรนด์" ทั้งหมด → หน้าจอดูแพงและไม่วุ่นวาย
2. **ไล่จากสงบไปเข้ม** — บนสุดขาวอมเทาเกือบเรียบ (ที่วางตัวหนังสือ) → พีช/ชมพูอ่อน → ภูเขาสีชมพูบานเย็น ม่วง-น้ำเงิน ส้มแดง มีแถบเขียวมะกอกจาง ๆ
3. **เกรนหยาบแบบงานพิมพ์** — noise ชัด ทำให้ไล่สีไม่ดูเป็นดิจิทัลเรียบ ๆ
4. **ตัวอักษรเรียบ น้ำหนักน้อย** — หัวข้อ medium ไม่ bold · เนื้อหาเทากลาง 14–15px · ช่องไฟปกติ
5. **องค์ประกอบโต้ตอบ = สี่เหลี่ยมมุมมน กรอบ 1px เทาอ่อน พื้นขาวโปร่ง** (ปุ่มโซเชียล)
6. **เส้นคั่นบางเส้นเดียว** แทนกล่อง/เงา · ลิงก์ใช้สีม่วงเข้มสีเดียว (`--c-accent`) + ขีดเส้นใต้
7. **โลโก้ทึบ หนัก** ตัดกับตัวหนังสือที่เบา — จุดเดียวในหน้าที่ "ดำเต็ม"

หลักที่เอามาใช้: **"หน้าจอทำงานเป็นขาว-ดำ · แบรนด์อยู่ในภาพศิลป์ · สีบน UI มีไว้บอกสถานะเท่านั้น"**

## 3 · ระบบดีไซน์ใหม่ (Design tokens)

ทุกค่าอยู่ใน token ชุดเดียว — เว็บ (`app/globals.css` `@theme`) และคอนโซล (`app/(app)/console.css` `--c-*`) ชี้ไปที่ชุดเดียวกัน · ไม่มีสีฝังในคอมโพเนนต์ (ตอนนี้คอนโซลทำได้แล้ว เว็บต้องตาม)

ป้ายสถานะ: พื้นสีจาง 8% + ตัวหนังสือสีเต็ม + จุดสีเล็กหน้าคำ (คนตาบอดสียังแยกได้จากคำ)

### 3.3 สีภาพศิลป์ "Ridge" (แบรนด์)

| ชั้น | สี (ร่าง) |
|---|---|
| ท้องฟ้า | `#f4f5f8` → `#fbe9e4` (พีช) → `#f9d3dc` (ชมพูอ่อน) |
| สันเขา 1 | ชมพูบานเย็น `#ff3d8b` → `#e0359a` |
| สันเขา 2 | ม่วง-น้ำเงิน `#6a5cff` → `#3b4fd8` |
| สันเขา 3 | ส้มแดง `#ff4a1c` → `#d9301f` |
| แถบเน้น | มะกอก/ทอง `#b8b25a` (บาง โปร่ง) |
| เกรน | noise ขาวดำ · `soft-light` 50–60% · ใช้ `.grain` เดิมได้ |

ใช้กับ: เว็บ (hero · footer · หน้าราคา) · หน้า login/สมัคร · แถบหัวหน้าแรกของคอนโซล (บางมาก) · หน้าว่าง/หน้าเริ่มต้น · OG image
**ห้ามใช้** เป็นพื้นหลังตาราง ฟอร์ม หรือข้อความยาว — อ่านไม่ออกและแย่งสายตา

### 3.4 ตัวอักษร

- ละติน + ตัวเลข: **Inter** (400 · 500 · 600) — ตัวเลขในตาราง `tabular-nums`
- ไทย: ดู **D2** · ข้อเสนอ **Anuphan** (Cadson Demak · ไม่มีหัว ทรงเรขาคณิต เข้ากับ Inter) หรือคง **IBM Plex Sans Thai** (เปลี่ยนน้อยสุด)
- stack: `Inter, <ไทย>, system-ui` — เบราว์เซอร์จะใช้ Inter กับอักษรละตินและตกไปใช้ฟอนต์ไทยกับอักษรไทยเอง
- ขนาด: เนื้อหา 15px · ตาราง 14px · คำกำกับ 13px (ไม่ต่ำกว่านี้) · H1 คอนโซล 28px medium · H1 เว็บ clamp(40–88px) weight 500 letter-spacing −0.02em
- เลิกใช้ mono ตัวพิมพ์ใหญ่ถ่างช่องไฟกับป้ายภาษาไทย (มี `labelClass` แยกอยู่แล้ว · ป้ายอังกฤษที่เหลือเปลี่ยนเป็นไทย)
- โหลดผ่าน `next/font` (self-host อยู่แล้ว · CSP `font-src 'self'` ไม่ต้องแก้) · ตรวจขนาดฟอนต์รวมไม่เกินเดิม +40KB

### 3.5 รูปทรงและระยะ

- มุมมน: การ์ด 12px · ปุ่ม/ช่องกรอก 8px · ป้าย 999px
- การ์ด: พื้นขาว · กรอบ 1px `line` · **ไม่มีเงา** (เงาเฉพาะเมนูลอย/หน้าต่าง)
- ระยะตามตาราง 4/8 · ช่องว่างระหว่างการ์ด 16 · ในการ์ด 20–24
- ปุ่ม 3 แบบเท่านั้น:
  - **หลัก**: พื้นดำ ตัวขาว (1 ปุ่มต่อพื้นที่)
  - **รอง**: พื้นขาวโปร่ง กรอบ `line-2` (แบบปุ่มโซเชียลในภาพ)
  - **อันตราย**: ตัวแดง กรอบแดงจาง
  - ไอคอนปุ่ม (⚙ · ผู้ใช้ · ค้นหา): สี่เหลี่ยม 36px มุม 8px กรอบบาง — เหมือนภาพอ้างอิง
- เป้าแตะขั้นต่ำ 44px บนมือถือ (มี `min-h-11` อยู่แล้วบางจุด → ทำให้ทั่ว)

### 3.6 โลโก้

ปัจจุบัน: สามเหลี่ยมเส้นบาง 1.1px — หายไปเมื่อย่อเล็ก และไม่มีน้ำหนักแบบในภาพ
ข้อเสนอ: คงแนวคิด "จุดบนยอดสามเหลี่ยม" (parallax = มองจากสองมุม) แต่ทำเป็น **รูปทึบ** เส้นหนา 2.5px หรือสามเหลี่ยมซ้อนสองชั้นเหลื่อมกัน · wordmark "Parallax" ตัวพิมพ์เล็ก-ใหญ่ Inter 600 แทนตัวใหญ่ถ่างช่องไฟ → ดู **D3**
ทำ 3 แบบร่างเป็น SVG ให้เลือก · อัปเดต `components/brand.tsx` · `app/icon.svg` · `opengraph-image.tsx`

### 3.7 ธีมมืด

คงไว้เป็นตัวเลือก (คุกกี้ `parallax_theme`) · เปลี่ยนเป็นเทาเข้มกลาง (`#0e0e10` / การ์ด `#17171a`) แทนกรมท่า · ภาพศิลป์ใช้ได้ทั้งสองธีม (ท้องฟ้าเป็นสีเข้มแทน)

## 5 · นามบัตร: ถ่าย · อัปโหลด · หลายใบ (H5)

### 5.1 ขั้นตอนผู้ใช้

1. หน้า **เพิ่มนามบัตร** มี 3 ทาง: **ถ่ายรูป** (เปิดกล้องหลังบนมือถือ) · **อัปโหลดรูป** (เลือกได้หลายไฟล์ / ลากวาง) · **พิมพ์เอง** (ของเดิม)
2. ใส่ชื่องานและวันที่ครั้งเดียวต่อชุด (เหมือนเดิม)
3. รูปแต่ละใบขึ้นเป็นแถวในตาราง พร้อมรูปย่อ · สถานะ "กำลังอ่าน…" → อ่านเสร็จเติมช่อง ชื่อ · ตำแหน่ง · บริษัท · อีเมล · โทร
4. ช่องที่ไม่มั่นใจมีขอบอำพัน "ตรวจช่องนี้" · แก้ในตารางได้ทันที · ลบแถวได้ · ถ่ายต่อได้เรื่อย ๆ (ปุ่ม "ถ่ายใบถัดไป")
5. กด **บันทึก N ใบ** → ส่งเข้า `captureCardsAction` เดิม → ผลต่อใบ: ใหม่ / มีอยู่แล้ว / ส่งรอตรวจ / ไม่รับ (ตัวตรวจคนซ้ำเดิมทำงานเหมือนเดิม)
6. จำกัดชุดละ 50 ใบ (`CARD_BATCH_MAX`) · เกินแล้วบอกให้แบ่งชุด

### 5.2 การอ่านรูป — ค่าตั้งต้น: อ่านในเครื่องผู้ใช้

เหตุผล: นามบัตรมีอีเมล/เบอร์โทร และกติกาเดิมคือ **ข้อมูลติดต่อไม่ส่งให้ AI** · อ่านในเบราว์เซอร์ = รูปไม่ออกจากเครื่องเลย

- ใช้ **tesseract.js** (ภาษา `tha+eng`) · โหลดเฉพาะตอนเปิดหน้านี้ (dynamic import) ไม่ถ่วงหน้าอื่น
- โฮสต์ไฟล์เองทั้งหมดใน `public/ocr/` (worker · wasm core · traineddata ไทย/อังกฤษแบบ fast ~3–5MB) — ไม่ดึงจาก CDN
- CSP: เพิ่ม `'wasm-unsafe-eval'` ใน `script-src` และ `worker-src 'self' blob:` **เฉพาะเส้นทาง `/app/vault/cards`** (proxy.ts ตั้ง CSP ต่อคำขออยู่แล้ว) · เส้นทางอื่นเข้มเท่าเดิม
- ก่อนอ่าน: ย่อรูปเหลือด้านยาว 1600px · หมุนตาม EXIF · ขาวดำ + เพิ่มคอนทราสต์ (canvas) · อ่านทีละ 2 ใบพร้อมกัน
- แยกช่องด้วยกฎ (`lib/shared/card-parse.ts` — ทดสอบได้ไม่ต้องมีเบราว์เซอร์):
  - อีเมล: regex · เว็บไซต์: `www.`/`.co.th`/`.com`
  - โทร: `0x-xxx-xxxx` · `+66` · `0x-xxxx-xxxx` · มือถือ vs สำนักงาน (เก็บเบอร์มือถือก่อน) · ตัด Fax
  - บริษัท: บรรทัดที่มี บริษัท/จำกัด/(มหาชน)/Co., Ltd./Group/Corporation
  - ตำแหน่ง: บรรทัดที่มีคำ ผู้จัดการ/ผู้อำนวยการ/Manager/Director/Engineer/Officer/CEO…
  - ชื่อ: บรรทัดใหญ่ที่เหลือที่ไม่ใช่สามอย่างบน · คำนำหน้า นาย/นาง/คุณ/Mr./Ms. ตัดออก
  - นามบัตรสองภาษา: เลือกฝั่งที่อ่านได้มั่นใจกว่า · อีกฝั่งเก็บเป็น "ชื่ออีกภาษา" ถ้ามีช่อง
- **ไม่เก็บรูป** — รูปอยู่ในหน่วยความจำของแท็บจนบันทึกเสร็จ แล้วทิ้ง · บอกผู้ใช้ตรง ๆ ใต้ปุ่ม: "รูปไม่ถูกอัปโหลด อ่านในเครื่องนี้"
- ด่านเดิมทั้งหมดยังอยู่: ต้องมีวัตถุประสงค์นามบัตร (S1) · สิทธิ์ `write` · บัญชีสมัครเองที่ยังไม่ผ่านเพนเทสต์ใช้ได้เฉพาะข้อมูลสมมุติ (`importBlockedReason`) — **ไม่ผ่อน**

### 5.3 ทางเลือกเสริม (ไม่ทำในรอบนี้ — รอตัดสินใจ D4)

อ่านด้วย Claude (แม่นกว่ามากกับนามบัตรไทยที่ฟอนต์ตกแต่ง) — แต่ต้องส่งรูปที่มีข้อมูลติดต่อออกนอกระบบ ขัดกับกติกาปัจจุบัน
ถ้าจะทำ: เจ้าของบัญชีเปิดเอง · บัญชีชำระเงินเท่านั้น · บันทึกใน audit log ว่าใบไหนส่งไป · ไม่เก็บรูป · ระบุใน DPA

### 5.4 ทดสอบ

- `verify/card-parse.mts` — นามบัตรตัวอย่าง 30 แบบ (ข้อความดิบที่ OCR อ่านได้ → ช่องที่คาด) ไทย อังกฤษ สองภาษา เบอร์หลายรูปแบบ
- ทดสอบในเบราว์เซอร์: อัปโหลดรูปนามบัตรสมมุติ 5 ใบ (สร้างเองใน `verify/fixtures/cards/` — ห้ามใช้นามบัตรคนจริง) → ตาราง → บันทึก → เจอในผู้ติดต่อ
- มือถือ 375px: ปุ่มถ่ายเปิดกล้อง · ตารางเลื่อนแนวตั้งเป็นการ์ดต่อใบ
- เป้าความแม่น: อีเมล/โทร ≥ 95% · ชื่อ/บริษัท ≥ 80% บนชุดทดสอบ · ต่ำกว่านั้นยังใช้ได้เพราะมีขั้นตรวจก่อนบันทึก
